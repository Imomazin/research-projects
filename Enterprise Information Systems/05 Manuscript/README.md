# Manuscript

Primary target: **Enterprise Information Systems**.

The manuscript will be written as an enterprise information-systems contribution, not as a narrow federated-learning benchmark. The central problem is how institutions can collaborate on machine learning when data cannot be centralised, local distributions differ and participants may be unreliable or adversarial.

The repository will keep the paper separate from Meridian code while linking every claimed method and empirical result to a stable Meridian commit/release.
