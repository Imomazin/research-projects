# Research Design

P3 is designed around a real build transition from heuristic multi-touch attribution to causal decision intelligence.

Core causal chain:

`journey events -> causal graph -> identification -> treatment-effect estimation -> counterfactual attribution -> causal revenue pathways -> constrained budget intervention -> uplift recommendation`

The design must explicitly define treatment, outcome, unit, timing, confounders, mediators, selection mechanisms and estimand before any model is interpreted causally.

Orbit's current first-touch, last-touch, linear, time-decay and weighted models remain frozen as non-causal baselines.
