# Data

P3 benefits materially from external datasets because causal claims need more than Orbit's current product fixtures.

The data strategy deliberately combines:

- a real large-scale attribution/journey dataset
- a randomised uplift benchmark with known treatment assignment
- an independent commerce transaction dataset for external commercial structure
- optional approved SkillHubs anonymised campaign data
- semi-synthetic journeys with known causal ground truth for method-recovery tests

Raw large datasets are not committed here. This folder stores source records, licences, acquisition scripts, checksums, transformations and analysis-ready derived artefacts where redistribution is permitted.
