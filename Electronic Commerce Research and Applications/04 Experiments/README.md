# Experiments

P3 experiments will compare Orbit's frozen heuristic baselines with the implemented causal engine.

Core families:

- E1: baseline attribution behaviour on reconstructed journeys
- E2: causal-effect recovery on semi-synthetic journeys with known ground truth
- E3: uplift/treatment-effect validation on the randomised Criteo uplift benchmark
- E4: observational causal attribution on Criteo attribution journeys with explicit identification assumptions
- E5: budget allocation and policy-value comparison under matched spend constraints
- E6: sensitivity to unobserved confounding, overlap violations, selection bias and measurement error
- E7: commerce-structure/external-validity checks using UCI Online Retail and, if approved, SkillHubs data

Results must separate causal identification evidence from predictive performance.
