# Research Projects

Private standalone repository for academic research projects, analysis and journal submissions.

## Active projects

- **Strategic Organization**: strategic capability asymmetry and occupational GenAI exposure
- **Enterprise Information Systems**: P2 privacy-preserving federated intelligence, paired with Meridian (`Imomazin/ppdl-cross-org-intelligence`)
- **Electronic Commerce Research and Applications**: P3 causal attribution and budget optimisation, paired with Orbit / AI MarTech Growth Intelligence (`Imomazin/ai-martech-growth-intelligence`)

Research material in this repository is intentionally kept separate from software, product and intelligence-build repositories. Each computational paper keeps a build-synchrony record that links manuscript claims to the relevant implementation, experiment configuration and code version.
