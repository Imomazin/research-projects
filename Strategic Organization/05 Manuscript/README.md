# Manuscript

This folder contains the controlled manuscript-preparation resources for the Strategic Organization submission.

## Start here

1. `JOURNAL_REQUIREMENTS.md` — current Strategic Organization submission requirements.
2. `WORLD_CLASS_MANUSCRIPT_STRATEGY.md` — paper framing, writing strategy, theory, methods, citation, tables, figures and claim discipline.
3. `C_MASTER_PROMPT.md` — complete handoff instruction for manuscript production.
4. `Exemplar Paper/Writing Style Blueprint.md` — rhetorical and structural blueprint derived from target-journal exemplars.

## Exemplar Paper/

Contains:

- Lin & Corley (2026) accepted Strategic Organization manuscript as a 243 KB reference PDF;
- the accepted manuscript source in Markdown;
- CC BY 4.0 licence;
- DOI/journal reference file;
- link to Figge, Anderson & Lewis (2026), the closest conceptual comparator for the present AI/capability argument;
- `Writing Style Blueprint.md`.

Exemplars are for journal calibration, argument architecture and style analysis only. Never copy wording.

## Authoritative empirical source

All manuscript statistics must be drawn from `../04 Analysis/Statistical Modeling/`. Do not calculate new headline results inside the manuscript folder and do not overwrite the validated analysis outputs.

## Draft control

New manuscript work should use explicit filenames and version control. Avoid uncontrolled duplicate drafts. Raw participant data remain in the private data folders and must not be copied into manuscript files.
