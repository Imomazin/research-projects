# Manuscript

This folder contains the controlled manuscript-preparation resources for the Strategic Organization submission.

## Start here

1. `POST_AUDIT_CLAIM_RESOLUTION.md` — **controlling empirical and drafting instruction after the 15 September 2026 audit.** If an older note conflicts with it, use this file and the supplementary S1-S11 outputs.
2. `REVIEWER_RISK_REGISTER.md` — twelve reviewer risks, the evidence behind each and the action that resolves it.
3. `JOURNAL_REQUIREMENTS.md` — current Strategic Organization submission requirements.
4. `WORLD_CLASS_MANUSCRIPT_STRATEGY.md` — paper framing, theory, methods, citation, tables and figures. Use only where consistent with the post-audit claim resolution.
5. `C_MASTER_PROMPT.md` — original manuscript-production handoff. It is no longer authoritative where later audit evidence changes a claim.
6. `Exemplar Paper/Writing Style Blueprint.md` — rhetorical and structural calibration. Never copy wording.

## Authoritative empirical sources

Headline estimates remain in `../04 Analysis/Statistical Modeling/`.

The post-audit robustness record is in `../04 Analysis/Supplementary Checks/Outputs/`, generated by `../04 Analysis/Supplementary Checks/supplementary-checks.py` against the same study data. The script reconciles its core values against `analysis_manifest.json` before running S1-S11.

The paper must therefore distinguish the validated headline estimates from the later sensitivity evidence. In particular, the raw 16.63-point domain contrast is not to be described as an objective AI/data capability deficit until common score calibration is documented. The adjusted occupational-exposure result is the central inferential finding.

## Exemplar Paper

The folder contains journal-calibration material only. The quantitative calibration article should be used for Methods and Results architecture while conceptual exemplars may still inform theory development. Exemplars are not sources for copying language.

## Draft control

Use explicit filenames and version control for new manuscript work. Do not create uncontrolled duplicate drafts. Any final manuscript should be checked sentence by sentence against `POST_AUDIT_CLAIM_RESOLUTION.md` before submission.
