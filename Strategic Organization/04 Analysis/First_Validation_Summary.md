## First-pass descriptive association

- Career exposure ordinal vs AI/data capability: Pearson r = 0.278
- Career exposure ordinal vs capability gap: Pearson r = 0.183

These are descriptive diagnostics only. They are not causal estimates and should not be used as the main inferential model.

## Analysis decision

Use career-interest ILO exposure as the primary external linkage. Preserve the official categorical exposure measure in the main models. Use the ordinal recode only for ordered specifications and robustness checks. Run sensitivity tests excluding Medium and Low-confidence occupation mappings.
