# Strategic Organization Submission Checklist

Use this only after the manuscript has passed the internal analytical and reference audits.

## Journal fit

- [ ] Submission type is Research Article.
- [ ] Contribution is explicitly at the intersection of strategic management and organization theory.
- [ ] Manuscript does not read as an intervention evaluation, employability report or generic skills survey.

## Manuscript requirements

- [ ] Total word count is within the journal's general 12,000-word guidance inclusive of abstract, references and tables.
- [ ] Manuscript is double-spaced in 12-point font.
- [ ] Abstract is unstructured and 100–150 words.
- [ ] Minimum five specific keywords are supplied.
- [ ] Review manuscript is fully anonymised.
- [ ] Separate title page contains authors, affiliations, acknowledgements and funding/grant information.
- [ ] Footnotes are sparse and essential only.

## Empirical integrity

- [ ] Every manuscript number has been checked against `04 Analysis/Statistical Modeling/`.
- [ ] Baseline n=200 and mapped analytical n=198 are not conflated.
- [ ] Career Interest is described as aspirational/target occupation.
- [ ] ILO GenAI exposure is described as occupation-level exposure.
- [ ] High exposure is identified as an analytical Gradient 3/4 grouping.
- [ ] Ordinal exposure recode is not misrepresented as an official ILO continuous score.
- [ ] Main occupation models state clustering across 19 ISCO-08 occupations and small-cluster t inference.
- [ ] The adjusted exposure null is reported accurately.
- [ ] No causal language is used for cross-sectional exposure models.
- [ ] n=12 follow-up evidence is appendix-only/noncausal or omitted.
- [ ] No intervention-effect claim appears anywhere.
- [ ] One-factor psychometric result and ceiling effects are disclosed.

## References

- [ ] SAGE Harvard style is applied consistently.
- [ ] Every in-text citation appears in the references.
- [ ] Every reference is cited in the manuscript.
- [ ] Author spelling and publication years match exactly.
- [ ] DOI/title/journal/volume/issue/pages have been verified.
- [ ] Published peer-reviewed versions replace preprints wherever available.
- [ ] No fabricated or unverified references remain.

## Tables and figures

- [ ] Main tables are limited to analytically necessary material.
- [ ] Main figures are numbered consecutively.
- [ ] All figures are at least 300 dpi.
- [ ] Figures remain legible in grayscale and use accessible distinctions.
- [ ] Table and figure notes define every abbreviation.
- [ ] Values reconcile exactly with analysis output.
- [ ] Initial-submission manuscript places each table/figure on a separate page at the end and includes placement markers in the text.

## Ethics and data governance

- [ ] Participant-level raw data remain private.
- [ ] Data-availability statement explains confidentiality/governance restrictions.
- [ ] No potentially identifying participant information appears in the manuscript or supplement.
- [ ] Any AI-use disclosure required by current SAGE policy has been handled accurately.

## Submission package

- [ ] Anonymised manuscript.
- [ ] Separate title page.
- [ ] Cover letter explaining Strategic Organization fit and contributions.
- [ ] Supplementary appendix.
- [ ] Data availability / ethics statement.
- [ ] Final figures and tables embedded/positioned according to journal instructions.
- [ ] All files open correctly and have clear names.

## Final editorial test

- [ ] First two manuscript pages make the strategic puzzle and theoretical contribution unmistakable.
- [ ] The paper distinguishes absolute capability sorting from relative AI/data readiness.
- [ ] Null adjusted findings are interpreted theoretically rather than hidden.
- [ ] Limitations bound the claims without undermining the contribution.
- [ ] No prose has been copied from exemplar papers.
- [ ] The paper is concise, coherent and ready for external review.
