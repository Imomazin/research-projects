# Strategic Organization Research Project

**Target journal:** Strategic Organization

**Research focus:** strategic capability asymmetry and occupational GenAI exposure using participant-level capability data linked to ISCO-08 and the ILO 2025 Generative AI occupational exposure framework.

## Folder structure

- **01 Primary Data**: participant source data in CSV and Excel
- **02 Secondary Data**: ILO occupational GenAI exposure source and lookup
- **03 Data Integration**: ISCO-08 crosswalks, analysis-ready data and integrated workbook
- **04 Analysis**: validation summaries, statistical outputs and robustness work
- **05 Manuscript**: manuscript development plus journal exemplars and writing-style blueprint
- **06 Submission**: final submission package

This project is maintained only in the private standalone `research-projects` repository and is intentionally separate from all software and intelligence-build repositories.
